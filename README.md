## Descrição 💬

Este projeto simula um **Carrinho de Compras online**, permitindo adicionar e remover produtos, além de exibir os valores individuais e o total em tempo real. Foi desenvolvido como parte de um desafio para praticar **HTML, CSS e JavaScript**, abordando interações comuns do cotidiano digital. 🛍️💻

## Funcionalidades 🚀

- **Adicionar produtos ao carrinho** com nome e valor 💡  
- **Remover itens individualmente** 🗑️  
- **Exibir valor total** do carrinho automaticamente 💰  
- **Interface leve, clara e responsiva** 🌐  

## Tecnologias Utilizadas 🔧

- **HTML5**: Estrutura e marcação do conteúdo 🧱  
- **CSS3**: Estilização e layout responsivo 🎨  
- **JavaScript**: Lógica de interação e manipulação do DOM ⚙️  

## Como Rodar o Projeto Localmente 🔥

### 1. Clone o repositório:

```bash
git clone https://github.com/jmgcorreia99/checkout-alura.git
```

### 2. Acesse a pasta do projeto:

```bash
cd carrinho-de-compras
```

### 3. Abra o arquivo index.html no navegador.

📂 Estrutura de pastas
```bash
📦 carrinho-de-compras
┣ 📁 img
┣ 📄 index.html
┣ 📄 style.css
┣ 📄 app.js
┣ 📄 README.md
```
